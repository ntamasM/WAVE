# WAVE v1.1.8

**Release date:** 2026-05-07

## Bug fixes

### Auto-update now actually works

**Fixed:** the in-app **Check for Updates** button (and the silent background update check on launch) was returning `HTTP 404` and could never find a new version.

Two problems were stacked on top of each other:

1. The Velopack feed URL pointed at the GitHub repo root (`https://github.com/ntamasM/WAVE`) instead of the assets path. Velopack fetches `RELEASES` / `releases.win.json` directly from whatever URL you give it — the repo root just returns the GitHub UI, so every probe got a 404.
2. The repository was private, so even a correct URL would have returned 404 to the unauthenticated update client.

The fix:

- `src/main/updater.ts` now points at `https://github.com/ntamasM/WAVE/releases/latest/download`, the canonical GitHub URL for serving release assets.
- The repository was made public so the update client can actually reach those assets.

### One-time manual upgrade required from v1.1.6 / v1.1.7

Because the broken URL is **baked into the v1.1.6 and v1.1.7 binaries**, those installs cannot auto-update themselves to v1.1.8 — they will keep getting 404. To get unstuck, **download and install v1.1.8 manually one time** from the GitHub Releases page. From v1.1.8 onward, automatic updates work normally.

## Changes

- Version bumped from `1.1.7` → `1.1.8`
- `UPDATE_URL` in `src/main/updater.ts` now uses the GitHub `releases/latest/download` path

## How to release future versions

1. Bump `version` in `package.json`
2. Add release notes file `release-notes/vX.Y.Z.md`
3. Create and push a tag: `git tag vX.Y.Z && git push origin vX.Y.Z`
4. GitHub Actions builds the app, packs it with `vpk`, and uploads to GitHub Releases automatically
5. Users on v1.1.8+ will receive the update silently on next launch
