# WAVE v1.1.7

**Release date:** 2026-05-07

## What's new

### Live customization preview

The **Settings → Customization** page now shows a real-time preview of the break lock screen. Tweak the background gradient, change the title, swap the logo, or recolor the timer — every change appears in the preview instantly, no need to wait for the next break to see how it looks.

### Star on GitHub button

The **About** page has a new **Star on GitHub** button. WAVE is free and open source, and a star is the easiest way to support the project.

### Refreshed About page

The About page copy has been updated to reflect features that have shipped recently — automatic updates, customization preview, stand-up reminders, and pre-lock warnings — so new users can see at a glance what the app actually does.

## Bug fixes

### Reminders no longer steal keyboard focus

**Fixed:** when the **Stand Up Reminder** or **Pre-Lock Warning** appeared while you were typing in another app, the overlay would steal keyboard focus and your keystrokes were silently dropped until the overlay closed.

The fix makes the reminder windows non-focusable and shows them via `showInactive()`, so they appear on top without taking focus from whatever you were doing. The lock screen itself still grabs focus (intentionally — it's a lock).

## Changes

- Version bumped from `1.1.6` → `1.1.7`
- New components: `LockScreenView` (shared between the real lock route and the preview) and `LockScreenPreview`
- `overlay-window.ts` now sets `focusable: false`; standup and pre-lock windows use `showInactive()`

## How to release future versions

1. Bump `version` in `package.json`
2. Add release notes file `release-notes/vX.Y.Z.md`
3. Create and push a tag: `git tag vX.Y.Z && git push origin vX.Y.Z`
4. GitHub Actions builds the app, packs it with `vpk`, and uploads to GitHub Releases automatically
5. Users on v1.1.6+ will receive the update silently on next launch
