# WAVE v1.1.3

**Release date:** 2026-05-06

## What's new

### Auto-update support (Velopack)

WAVE now ships as a proper Windows installer via [Velopack](https://velopack.io) and supports seamless automatic updates.

- On launch, WAVE silently checks for a new version in the background. If one is found, it downloads it and shows a Windows notification — no action required.
- A **Check for Updates** button is now available in **Settings → Updates**, letting you manually trigger a check at any time.
- When an update is downloaded, a **Restart & Update** button appears. Clicking it closes WAVE and installs the new version automatically.
- Delta updates mean subsequent releases download only the changed files, keeping update sizes small.

### New installer

The setup executable (`WAVE-Setup.exe`) is now built by Velopack. It installs to `%LocalAppData%\com.ntamadakis.wave` and creates Start Menu and Desktop shortcuts.

> **Migrating from v1.0.0:** The v1.0.0 installer used a different build system. Please uninstall the old version before installing v1.1.3.

## Changes

- Version bumped from `1.0.0` → `1.1.3`
- App ID updated from `com.wave` → `com.ntamadakis.wave`
- Removed NSIS / portable build targets (replaced by Velopack)
- Added GitHub Actions release workflow (`.github/workflows/release.yml`) for automated tag-triggered releases

## How to release future versions

1. Bump `version` in `package.json`
2. Create and push a tag: `git tag v1.x.x && git push origin v1.x.x`
3. GitHub Actions builds the app, packs it with `vpk`, and uploads to GitHub Releases automatically
4. Users on v1.1.3+ will receive the update silently on next launch
