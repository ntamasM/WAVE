# App Media (Private Assets)

This folder contains private application assets used internally by WAVE.

## Contents

- **Wave--icon.png** - Application logo (PNG format)
- **Wave--icon.svg** - Application logo (SVG format)

These assets are used for:

- Application window icon
- System tray icon
- Installer icon
- Lock screen display (when no custom logo is selected)

## Note

These files are bundled with the application and should not be modified by users. Users can customize the lock screen logo through the app's Customization settings, which stores custom media in the user data directory.
